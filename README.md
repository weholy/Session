# Сессия

Тренировочное приложение для iOS 26 (SwiftUI, Liquid Glass). Домашняя калистеника от старта семестра до контрольного теста. ИИ-тренер ведёт онбординг, собирает план на каждый день до конца семестра, каждую неделю разбирает прогресс и правит нагрузку.

## Как это работает

- Учебный год делится на два семестра, в конце каждого — контрольный тест. Даты теста задаются в настройках.
- ИИ (Groq) отвечает за онбординг, генерацию плана, недельный разбор, план на второй семестр, чат с тренером и разбор техники. Если сети нет — план строится формулой прогрессии, приложение работает.
- Пропущенная тренировка переносится долгом на следующую. Тяжесть долга растёт вместе с результатами. Три пропуска подряд — ИИ пересобирает остаток семестра.
- Дни отдыха привязаны к датам. Стрик при пропуске замирает.
- Данные только на устройстве (SwiftData), без входа и синхронизации.

## Сборка

Локальный Xcode не нужен. Проект генерируется XcodeGen и собирается в GitHub Actions на macOS-раннере, на выходе — неподписанный `.ipa` в релизе `latest`. Подпись и установка — на стороне пользователя (Sideloadly и т.п.).

Первый запуск:

1. `gh auth login -h github.com`
2. Создать приватный репозиторий и запушить `main`.
3. Добавить секрет: `gh secret set GROQ_API_KEY`
4. Дождаться сборки, скачать `.ipa` из релиза `latest`.

## Структура

```
project.yml                 конфигурация XcodeGen
.github/workflows/build.yml  сборка и публикация IPA
Config/                      xcconfig с ключом (реальный не коммитится)
Session/
  App/                       точка входа
  Navigation/                корневой контейнер, вкладки
  DesignSystem/              палитра, стекло, типографика
  Features/                  экраны по разделам
  Resources/                 Info.plist, ассеты
```
